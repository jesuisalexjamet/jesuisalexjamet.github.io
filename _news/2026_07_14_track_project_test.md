The first testing phase of the [TRACK]({{ track_project.url | relative_url }}) project is officially underway. A dedicated metadata block tailored for software traces has been integrated into the [BSC Dataverse](https://dataverse.bsc.es/) test instance. This initial pilot is expected to run through September, providing a crucial window to thoroughly validate the behavior of the metadata schema and refine our programmatic tools and APIs before the official deployment.
